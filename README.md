## 👨‍💻 Sobre Mí

Soy un desarrollador enfocado en la creación de soluciones tecnológicas robustas, combinando infraestructura en la nube, desarrollo web y nuevas tecnologías. Me apasiona el código limpio, la automatización y la educación tecnológica.

*   🔭 **Actualmente:** Desarrollador Web y Administrador de Contenidos en la PUCE Esmeraldas.
*   🎓 **Educación:** Cursando una Maestría en Inteligencia Artificial para la Educación en la UNEMI.
*   ☁️ **Enfoque:** Arquitectura Cloud, integraciones con IA generativa y diseño web moderno.
*   ⚡ **Intereses:** Sistemas de bajo nivel, open-source y optimización de flujos de trabajo.
